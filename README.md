# Gravity Team

Landing page for a crypto market-making company, with a responsive layout, a mobile menu and a slider.

**Live demo:** https://eshxyx.github.io/gravity-team/

## About

Learning project, built from a provided design mockup.

## Built with

- HTML
- CSS
- JavaScript
- jQuery
- [Slick](https://kenwheeler.github.io/slick/) carousel

## Run locally

```bash
git clone https://github.com/eshxyx/gravity-team.git
cd gravity-team
```

Then open `index.html` in your browser. No build step is needed.
